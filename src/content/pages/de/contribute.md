## Offen für alle

Scitura ist **Open Source** und eine **offene Bildungsressource (OER)**. Der gesamte Quellcode liegt öffentlich auf [GitHub](https://github.com/gori-creator/Simulations). Das heißt:

- **Nachprüfbar:** Jede Schule und jede Datenschutzbeauftragte kann selbst nachsehen, dass Scitura keine Daten sammelt und keine fremden Server lädt.
- **Frei nutzbar:** Texte, Aufgaben und Bilder dürfen Sie in Arbeitsblätter übernehmen, verändern und weitergeben (CC BY-SA 4.0).
- **Gemeinsam besser:** Alle können Fehler melden, Texte verbessern und eigene Simulationen beitragen.

## Offizielle und Community-Simulationen

- **Offizielle Simulationen** sind von Scitura fachlich und didaktisch geprüft.
- **Community-Simulationen** tragen ein gelbes Abzeichen <span class="badge badge--community">Community</span> und den Namen der Person, die sie gebaut hat. Sie sind **technisch geprüft** (automatische Tests, Sicherheitsprüfung, Durchsicht des Codes), aber **fachlich noch nicht**. Nach der fachlichen Prüfung werden sie offiziell.

## So können Sie mitmachen

| Sie möchten … | So geht's |
| --- | --- |
| einen **Fehler melden** oder eine **Idee** schicken | über das [Kontaktformular](../kontakt/) – ganz ohne Konto |
| eine **eigene Simulation** bauen | mit einem KI-Assistenten und unserer [Schritt-für-Schritt-Anleitung mit fertigen Prompts](https://github.com/gori-creator/Simulations/blob/main/docs/MITMACHEN-SIMULATION.md) |
| **Texte verbessern** oder **übersetzen** | als Pull Request auf GitHub ([Regeln](https://github.com/gori-creator/Simulations/blob/main/CONTRIBUTING.md)) |
| Scitura **an Ihrer Schule bekannt machen** | Link teilen, im Kollegium zeigen – das hilft am meisten |

Ohne GitHub-Erfahrung? Schicken Sie Ihre Idee oder Ihre Dateien einfach über das [Kontaktformular](../kontakt/), wir bauen sie ein.

## Was jede Simulation erfüllen muss

- **Nur rechnen und zeichnen:** keine Verbindungen ins Internet, kein Zugriff auf Daten, keine Werbung. Ein automatischer Test prüft das bei jedem Beitrag.
- **Datenschutz:** keine externen Schriften, Skripte oder Statistikdienste.
- **Zweisprachig:** Deutsch und Englisch.
- **Für alle Geräte:** vom Handy bis zum Whiteboard, hell und dunkel.
- **Fachlich sauber:** Formeln und Begriffe wie im Unterricht, mit nachgerechneten Tests.
