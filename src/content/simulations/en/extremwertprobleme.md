## What is it about?

Objective function → constraint (reduce to one variable) → domain → set the derivative to zero → check the type and the boundary values.

*Box:* $V(x) = x(30 - 2x)(20 - 2x)$ is largest for $x \approx 3.92$ cm. *Can:* the surface $S(r) = 2\pi r^2 + \frac{2V}{r}$ is smallest for $r = \sqrt[3]{V/(2\pi)}$, where $h = 2r$.
