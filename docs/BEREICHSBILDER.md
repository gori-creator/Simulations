# Bereichsbilder, Abschnitts-Illustrationen und Referenzdesign (Prompts)

Stand: 01.11.2026. Für den Umbau der Simulationsseiten (Kopfbereich mit Bild, Abschnitte mit kleinen Illustrationen). Alle Bilder im selben **hellblau-schematischen Stil** wie die Vorschaubilder (`docs/VORSCHAUBILDER.md`), damit alles wie aus einem Guss wirkt. Die Seite funktioniert ohne diese Bilder (dann nimmt der Kopfbereich das Vorschaubild der Simulation bzw. zeigt keine Illustration); jedes gelieferte Bild ersetzt das automatisch.

## So geht's (für Codex oder ein anderes Bildwerkzeug)

1. Zweig `claude/exciting-gauss-noh1h9` von `gori-creator/Simulations` frisch holen.
2. Bilder **mit dem Bildwerkzeug** erzeugen (nicht per Code/SVG zeichnen), Prompt jeweils **wörtlich** übernehmen.
3. Als **Stilvorlage** bei jedem Bild zwei, drei vorhandene Vorschaubilder mitgeben, z. B. `src/assets/vorschau/fadenpendel.webp`, `src/assets/vorschau/bruchteile.webp`, `src/assets/vorschau/lineare-funktion.webp` („im selben Stil: gleiche Linienstärke, gleiche Farben, gleicher heller Hintergrund“).
4. Alle Bilder einer Gruppe **im selben Verlauf nacheinander** erzeugen.
5. Vor dem Speichern prüfen, sonst neu erzeugen: keine Schrift/Zahlen/Pseudo-Schrift, kein Glühen, kein dunkler Hintergrund, Motiv vollständig, fachlich richtig (Strahlengänge, Kräfte, Graphen), bei den Bereichsbildern **linke Hälfte frei**.
6. Speichern unter den angegebenen Dateinamen, Commit und Push auf `claude/exciting-gauss-noh1h9`. Keinen Anwendungscode ändern.

Den **Dunkelmodus** erzeuge ich automatisch aus den hellen Bildern (Blaupausen-Fassung), dafür nichts extra generieren.
