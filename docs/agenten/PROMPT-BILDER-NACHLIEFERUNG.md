# Bildauftrag: 9 Bilder neu erzeugen (zweiter Versuch)

Du erzeugst Bilder für eine kostenlose Lernplattform mit Mathe- und Physik-Simulationen. Diese 9 Bilder waren beim ersten Versuch unbrauchbar – der Grund steht jeweils dabei. Achte **genau** auf Format, Blickrichtung und Durchsichtigkeit.

**So arbeitest du**
1. Pro Antwort genau ein Bild, von oben nach unten. Über jedes Bild eine Zeile: `Bild <Nr> · <dateiname>.png`.
2. Den englischen Prompt wörtlich verwenden.
3. **Hintergrund „transparent“:** echte Transparenz. Wenn du das nicht kannst: völlig einfarbiger, flacher Hintergrund ohne Schatten (reines Weiß; bei hellen/gläsernen Gegenständen reines Grün #00FF00).
4. **Seitenverhältnis einhalten.** Wenn du nur quadratisch kannst: Gegenstand vollständig im Bild, die lange Seite fast ganz ausgefüllt, Rest leer.
5. Vor dem nächsten Bild selbst prüfen (Grund des ersten Fehlschlags beachten) und ggf. neu erzeugen.
6. Grundregeln: fotorealistisch, weiches Studiolicht von links oben, keine harten Schatten, kein Text, keine Zahlen, keine Skalen, keine Logos, keine Personen, keine Hände.
