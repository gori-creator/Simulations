# Startnachricht für einen neuen Chat

Vor dem Einfügen: in der neuen Sitzung `/model` auf Opus stellen und den Aufwand auf „Mittel“. Auf dem Branch `claude/sleepy-goodall-ddchwy` arbeiten.

---

Lies `docs/agenten/UEBERGABE.md` (Abschnitt 0 „Spar-Modus“ hat Vorrang), dazu `CLAUDE.md`, `docs/agenten/AUFTRAG.md` und `docs/agenten/SPICKZETTEL.md`.

Arbeitsweise: Du baust die Simulationen **selbst oder mit genau einem Agenten, immer nur eine Simulation am Stück**. Nichts läuft automatisch, keine Routine, kein Wecker. Nach jeder Simulation: `npm run verify`, committen, pushen, kurz berichten und auf mein „weiter“ warten.

Reihenfolge: zuerst `docs/agenten/wip/LIES-MICH.md` (angefangene Reste von T01, P06, M24: cavalieri, rotationskoerper), dann die Warteschlange in `docs/agenten/WARTESCHLANGE.md`.

Fang mit der ersten offenen Simulation an. Antworte auf Deutsch, knapp, ohne Fachjargon (ich lese am Handy).
